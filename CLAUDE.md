## Project Overview

This is a bilingual (Japanese/English) corporate website for ooo.engineering, built with Vite and deployed on Firebase Hosting. The site features:
- Language switching between Japanese and English
- D-DIN font for English text
- Animated background using Vanta.js
- Responsive design for all devices
- Corporate sections: Home, About, Services, and Contact

## Commands

### Development
- **Install dependencies**: `npm install`
- **Start development server**: `npm run dev` (runs on http://localhost:3000)
- **Build for production**: `npm run build` (outputs to public/ directory)
- **Preview production build**: `npm run preview`

### Environment Variables
The project uses environment variables to automatically switch between development and production URLs:
- `.env.development` - Local paths for development (e.g., `/digital/`)
- `.env.production` - Full subdomain URLs for production (e.g., `https://digital.ooo.engineering`)

Service links are automatically generated based on the environment, so no manual changes are needed when deploying.

### Deployment
- **Deploy to production**: `npm run deploy` (builds and deploys)
- **Deploy preview**: Firebase automatically creates preview deployments for pull requests

## Architecture

The project uses Vite as a build tool:
- `src/` - Source files for development
  - `src/index.html` - Main HTML file with bilingual content
  - `src/style.css` - All styling including D-DIN font for English
  - `src/main.js` - JavaScript for language switching and interactions
  - `src/assets/` - Static assets (logo.png)
- `public/` - Build output directory (generated by Vite)

### Key Technologies
- **Vanta.js**: Used for the animated dots background effect
- **Three.js**: Required dependency for Vanta.js animations
- **Firebase Hosting**: Static site hosting with automatic SSL

### GitHub Actions Workflows
- **firebase-hosting-merge.yml**: Automatically deploys to production when changes are merged to main
- **firebase-hosting-pull-request.yml**: Creates preview deployments for pull requests

## Development Notes

- All changes should be made to files in the `public/` directory
- The site uses responsive design with viewport-based sizing
- The Vanta.js dots animation is configured with white dots on a white background for a subtle effect
- Firebase hosting is configured to serve all routes through index.html (SPA-style routing)
