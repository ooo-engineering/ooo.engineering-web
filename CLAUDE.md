## Project Overview

This is a multilingual (Japanese/English) corporate website for ooo.engineering, built with Vite and deployed on Firebase Hosting. The site consists of a main corporate site and three service subdomains:

- **Main Site**: Corporate information, company overview, and service links
- **Digital** (digital.ooo.engineering): Wooow app - handwriting-based location sharing app, and Raylie - flight view guide app (`/digital/raylie.html`, assets in `src/assets/raylie/`)
- **Atelier** (atelier.ooo.engineering): Bespoke leather goods
- **Edu** (edu.ooo.engineering): Next-generation IT creator education

### Key Features
- Bilingual support (Japanese/English) with language switcher
- D-DIN font for English text, Noto Sans JP for Japanese
- Animated backgrounds (Vanta.js on main site, Spline 3D on service pages)
- Responsive design for all devices
- Environment-based URL switching for development/production

## Development Workflow

### 1. Initial Setup
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
- Runs on http://localhost:3000 (or 3001 if port is taken)
- Hot module replacement enabled
- Environment variables use local paths (e.g., `/digital/`)

### 3. Build for Production
```bash
npm run build
```
- Compiles all source files from `src/` to `public/`
- Optimizes assets and bundles JavaScript
- Updates paths for production environment

### 4. Preview Production Build
```bash
npm run preview
```
- Serves the built files from `public/` directory
- Useful for testing production build locally

### 5. Deploy to Firebase
```bash
npm run deploy
```
- Builds the project first
- Deploys to Firebase Hosting

## Environment Variables

The project uses different URLs for development and production:

### Development (.env.development)
```
VITE_DIGITAL_URL=/digital/
VITE_ATELIER_URL=/atelier/
VITE_EDU_URL=/edu/
VITE_LINK_TARGET=_self
```

### Production (.env.production)
```
VITE_DIGITAL_URL=https://digital.ooo.engineering
VITE_ATELIER_URL=https://atelier.ooo.engineering
VITE_EDU_URL=https://edu.ooo.engineering
VITE_LINK_TARGET=_blank
```

Service links are automatically generated based on the environment.

## Adding New Pages

### 1. Add a new HTML page in the appropriate directory
For example, to add a terms of service page to digital:
```bash
# Create the file in src/digital/terms.html
```

### 2. Update vite.config.js
Add the new page to the build inputs:
```javascript
input: {
  main: resolve(__dirname, 'src/index.html'),
  digital: resolve(__dirname, 'src/digital/index.html'),
  digitalPrivacy: resolve(__dirname, 'src/digital/privacy.html'),
  digitalTerms: resolve(__dirname, 'src/digital/terms.html'), // New page
  // ... other pages
}
```

### 3. Add navigation links
Update the relevant HTML files to include links to the new page.

### 4. Build and test
```bash
npm run build
npm run preview
```

## Language Support

All text content should include both Japanese and English versions:

```html
<!-- Use data attributes for bilingual content -->
<p data-ja="日本語テキスト" data-en="English text">日本語テキスト</p>

<!-- The language switcher in main.js handles the switching -->
```

## Styling Guidelines

1. **Global styles** go in `src/style.css`
2. **Service-specific styles** go in their respective CSS files
3. **Font usage**:
   - Japanese: Noto Sans JP
   - English: D-DIN (automatically applied when language is switched)
4. **CSS Variables** defined in `:root` for consistency:
   - `--primary-color`: #000000
   - `--secondary-color`: #333333
   - `--accent-color`: #ff6600
   - `--border-color`: #e0e0e0

## Common Tasks

### Adding a new service subdomain
1. Create a new directory in `src/` (e.g., `src/newservice/`)
2. Add HTML, CSS, and JS files
3. Update `vite.config.js` to include new entry points
4. Add environment variables for the new service URL
5. Update `src/main.js` to include the new service in the services grid
6. Configure DNS and Firebase hosting for the subdomain

### Updating the privacy policy
1. Edit `src/digital/privacy.html`
2. Update both Japanese and English content
3. Update the "last updated" date
4. Build and deploy

### Modifying the main navigation
1. Edit the relevant HTML files in `src/`
2. Ensure bilingual data attributes are included
3. Test language switching functionality
